# DermVision

**AI-powered skin lesion classification using PyTorch, ResNet18 transfer learning, Grad-CAM explainability, and Streamlit deployment.**

DermVision is an end-to-end computer vision project for **multi-class skin lesion classification** built with **PyTorch**. The project began with a **custom CNN baseline model**, followed by a transition to **ResNet18 transfer learning**, which significantly improved performance and generalization. The final application predicts one of seven skin lesion categories from dermoscopy images and provides **Grad-CAM visualizations** to improve model interpretability.

## Model Development

### CNN Baseline

A custom CNN model was trained with data augmentation as the initial benchmark.

| Model | Validation Accuracy | Test Accuracy |
|---------|---------:|---------:|
| CNN (from scratch) | **75.37%** | **73.59%** |

While the CNN learned useful image features, performance plateaued and struggled to generalize effectively.

### Final Model – ResNet18 Transfer Learning

A pretrained ResNet18 model was fine-tuned on the HAM10000 dataset.

| Model | Validation Accuracy | Test Accuracy |
|---------|---------:|---------:|
| ResNet18 | **90.08%** | **88.02%** |

The transition from a custom CNN to transfer learning resulted in a significant improvement in both validation and test performance.

## Supported Classes

The model predicts one of the following seven skin lesion categories:

- Actinic Keratoses (AKIEC)
- Basal Cell Carcinoma (BCC)
- Benign Keratosis-like Lesions (BKL)
- Dermatofibroma (DF)
- Melanoma (MEL)
- Melanocytic Nevus (NV)
- Vascular Lesions (VASC)

---

## Explainability with Grad-CAM

Grad-CAM is integrated into the application to visualize the image regions responsible for model predictions.

This helps improve interpretability and provides insight into how the model arrives at its predictions.

## Dataset

This project uses the **HAM10000 (Human Against Machine with 10000 training images)** dataset.

Dataset Link:

https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000

The dataset is not included in this repository because of size limitations.

---

## Dataset Challenges

One of the most significant challenges in this project was **class imbalance**.

The HAM10000 dataset has a highly uneven distribution of images across the seven skin lesion categories. Classes such as **Melanocytic Nevus (NV)** contain a large number of training images, while categories such as **Dermatofibroma (DF)** and **Vascular Lesions (VASC)** have significantly fewer examples.

This imbalance made the classification task more challenging and affected the model’s ability to generalize across the minority classes. The CNN baseline was particularly affected by this imbalance, which motivated the transition to **ResNet18 transfer learning**.

To improve performance, I used **data augmentation in the CNN baseline**, **transfer learning with ResNet18**, and evaluated the models using **confusion matrices, classification reports, and Grad-CAM visualizations**. Despite these improvements, the minority classes remained more challenging, which is reflected in the project’s limitations and prediction performance.

## Medical Disclaimer

**DermVision is an educational and demonstration project and should not be used for medical diagnosis, treatment, or clinical decision-making.**

The predictions generated by this model are based on patterns learned from the **HAM10000 dataset** and may be incorrect, even when the model reports high confidence. Skin lesion diagnosis requires evaluation by a qualified dermatologist and may involve additional clinical examination, dermoscopy, biopsy, and other diagnostic procedures.

This application is intended solely for **demonstrating deep learning, computer vision, model evaluation, explainability, and deployment techniques**. It should not be relied upon for any medical purpose or as a substitute for professional healthcare advice.

If you have concerns about a skin lesion or any medical condition, consult a licensed healthcare professional.
