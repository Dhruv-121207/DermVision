MODEL INFORMATION

Inside DermVision

How DermVision was trained, how ResNet18 processes an image, and what Grad-CAM shows.

FINAL CLASSIFIER

ResNet18
Transfer learning

DermVision uses an ImageNet-pretrained ResNet18 convolutional network, fine-tuned on HAM10000 dermoscopy images. Its final classification layer was replaced to predict seven skin lesion categories.

DATASET

HAM10000

The model was trained using HAM10000, a collection of dermoscopic skin lesion images labelled across seven categories. The project code uses a stratified image-level split: 70% for training, 15% for validation and 15% for testing.

10,015Images in the full HAM10000 dataset
Dataset source: HAM10000. The dataset is not bundled with this application.
EXPLAINABILITY

Grad-CAM

Grad-CAM uses gradients from the model to generate a heatmap of image regions that influenced its prediction. Warm colours indicate stronger activation, not clinical evidence of disease.

TRAINING AND ARCHITECTURE

How the classifier was built

01 / PREPARATION

Preparing the images

Images are resized to 224 × 224 RGB and normalized using ImageNet channel statistics. During training, random horizontal flips and small rotations provide augmentation.

02 / FEATURE EXTRACTION

ResNet18 backbone

ResNet18 has 18 learned layers and residual connections that pass information across blocks. Its pretrained feature extractor learns image patterns, from edges and textures to more complex structures.

03 / CLASSIFICATION

Seven output classes

The original final layer is replaced with a linear layer producing seven scores. Softmax converts those scores into the class probabilities shown on the analysis page.

04 / MODEL TRAINING

Fine-tuning

The training script uses cross-entropy loss, Adam with a starting learning rate of 0.0001, a step scheduler and up to 20 epochs. It saves the checkpoint with the highest validation accuracy.

Evaluation uses an image-level split rather than a lesion-ID-grouped split, which can overestimate performance on unseen lesions.
